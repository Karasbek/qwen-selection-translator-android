# Qwen Selection Translator v0.2.0

## Изменения

- Интеграция AnkiDroid: выбор существующей колоды и типа заметки, предпросмотр и сохранение по явному нажатию.
- Использование существующих Cloze-шаблонов с полями `Front`, `Pinyin`, `Дополнение оборота`, `Image`, `Sound`; шаблоны и коллекция не перенастраиваются.
- Интерактивное скрытие слов и фраз в Explain. Все пропуски используют `c1`, создавая одну карточку. Похожие формы предлагаются, но скрываются только пользователем.
- Офлайн English US IPA из ipa-dict; точный поиск, выбор неоднозначных вариантов и ручное редактирование. Лицензии и атрибуция включены в APK.
- Explain переиспользуется целиком, включая пример: Anki не требует дополнительных Groq-вызовов.
- RAM-кэш успешных Explain/Translate: до 100 записей, TTL 30 минут, с учётом параметров запроса. Retry обходит кэш; тексты не сохраняются на диск.
- Локальная диагностика расхода Groq: токены, запросы, ошибки и сэкономленные кэшем вызовы, без телеметрии.
- Защита от повторной записи, предупреждения о дубликатах и безопасное состояние при неизвестном результате сохранения.

## Проверка и установка

- Honor KRJ-W09, Android 10 / API 29; AnkiDroid 2.25.1.
- 214 JVM-тестов; предыдущая полная Android-регрессия: 48 тестов и отдельный физический ReadEra smoke с fake Groq и офлайн IPA.
- Для релиза успешно выполнены testDebugUnitTest (214 тестов), assembleDebug, lintDebug и compileDebugAndroidTestKotlin с JDK 21, максимум двумя Gradle workers, без parallel. Lint: 0 ошибок, 14 прежних предупреждений.
- Пользователь подтвердил ручную проверку реальной Anki-карточки, c1, IPA, отсутствия лишних дубликатов и синхронизации с настольным Anki. При подготовке релиза новые заметки и платные Groq-запросы не выполнялись.
- **APK подписан debug-сертификатом**, как v0.1.0. Это не production signing key. Устанавливается поверх v0.1.0 при совпадении подписи без удаления приложения; настройки и зашифрованный API-ключ сохраняются.

## Ограничения

- Нужен Groq API key для обычных Explain/Translate; Anki-подготовка и IPA полностью локальные. Если Explain отсутствует, нужен готовый Explain или ручной текст.
- Для сохранения нужен доступ к официальному AnkiDroid API и совместимый существующий Cloze-тип с указанным порядком пяти полей. AnkiWeb-синхронизация выполняется пользователем в AnkiDroid.
- Подсветка родственных форм использует ограниченную английскую эвристику и может ошибаться. Проверка предпросмотра обязательна; формулировки не исправляются автоматически.
- IPA содержит английские US словарные формы; отсутствующая запись оставляет поле пустым, несколько вариантов требуют выбора. Произношение не угадывается.
- Изменение текста пересчитывает пропуски с предупреждением. Выделение фразы не прокручивает экран автоматически; черновик и RAM-кэш не переживают завершение процесса.
- Обнаружение дубликатов практическое, не абсолютное. При неизвестном результате записи проверьте AnkiDroid перед новой попыткой; автоматического повторного добавления нет.
